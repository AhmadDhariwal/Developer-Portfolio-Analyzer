## 1. Platform Request, Security & Caching Pipeline

```text
Angular 21 SPA (Zoneless + Standalone + Lazy Role Modules)
  └─▶ Shared/Feature Service (optional L0a in-memory Map/shareReplay or L0b localStorage TTL)
        └─▶ HttpClient ─▶ authInterceptor (attaches Bearer JWT unless X-Skip-Auth; handles 401 logout & 503 maintenance)
              └─▶ Express 5 (backend/index.js)
                    ├─ Global Middleware:
                    │    helmet CSP ─▶ cors ─▶ globalRateLimiter (process MemoryStore) ─▶ requestContextMiddleware
                    │    ─▶ express.json(100kb) ─▶ Maintenance Mode Gate (in-memory PlatformSettings snapshot)
                    │    ─▶ /uploads (B2 cookie/signed-URL or public local static) ─▶ metricsMiddleware
                    │    ─▶ auditLogMiddleware (persists POST/PUT/PATCH/DELETE to AuditLog)
                    ├─ Router Middleware:
                    │    protect / optionalProtect ─▶ authorizeRoles / requireRecruiterTenant
                    │    ─▶ requireOrganizationContext ─▶ platformSettingsMiddleware ─▶ rate-limiters / Mongo leases
                    ├─ Controller ─▶ Domain Service
                    │    ├─ L1 Process Memory Map (bounded LRU/FIFO or unbounded on specific legacy caches)
                    │    ├─ L2 Redis / Upstash (redisCacheService: atomic GET+PTTL Lua snapshot, graceful fallback)
                    │    ├─ L3 MongoDB Snapshot/Cache (TTL-indexed or SWR collections)
                    │    └─ Authoritative MongoDB + External APIs + AIProviderManager (Gemini → OpenAI → Groq → Anthropic → xAI)
                    └─ HTTP Response (`ETag` on Dashboard; `private, no-store` on sensitive/dynamic endpoints)
```

## 3. Traced End-to-End Critical Workflows

1. **Developer Evidence & Signal Propagation (`GitHub` / `Resume` → `Skill Gap` → `Recommendations` → `Portfolio` → `Dashboard`):**
   - `GithubAnalyzerComponent` enters with `savedOnly: true` (`0` external calls). Explicit `Sync GitHub` → `POST /api/github/analyze-save` → acquires `github-save:<userId>:<username>` lock → fetches GitHub → computes `githubHealthScore` → writes `Analysis`, `Repository`, `GitHubAnalysisCache` (`24h` SWR) and Redis → bumps evidence timestamps → FE `FrontendCacheInvalidationService.clearDeveloperSignalCaches()` clears local caches.
   - Downstream `Skill Gap` (`v9`) computes `signalHash` over `{ github, resume, careerContext, integrations }`; on mismatch it runs deterministic recompute (`0` automatic AI calls) and updates `AnalysisCache` (`7d`) + Redis (`15m`). `Recommendations` (`v7`) compares `sourceFingerprint`, computes deterministic cards (`0` AI calls), and sets `aiRefreshRecommended: true` if prior AI enrichment was superseded. `Dashboard` reads Mongo live (`ETag` + `304`) and displays exact freshness/staleness per source.
2. **Recruiter Invitation Onboarding & Hiring Loop (`Invite` → `Accept` → `Job` → `Match` → `Shortlist` → `Comparison`):**
   - Org Admin calls `POST /api/admin/invite-recruiter` → creates `Invitation` + queues `EmailDeliveryJob` via `emailRetryQueueService`.
   - Invited user opens `/invitations/accept/:token` → `POST /api/auth/accept-invite` claims pending invitation and atomically writes `User`, `Organization` link, `Membership`, and optional `Team` membership in one MongoDB transaction → FE calls `AuthService.adoptSession(user)` and routes to `/app/recruiter/profile?onboarding=recruiter`.
   - Recruiter creates `Job` (`POST /api/recruiter-hub/jobs`), triggers `POST /api/recruiter-hub/matches/generate` → `matchingService.listCandidates` checks `PlatformSettings.recruiter.candidateVisibility` (`public` | `organization` | `private`) + `User.isPublic` + `User.isActive` → hydrates `Analysis`, `ResumeAnalysis`, `PublicProfile`, `CareerSprint`, `WeeklyReport` in batches → `matchCalculator` computes 6-weight score → upserts `RecruiterMatch` transactionally.
   - Promoting to `RecruiterShortlist` (`POST /api/recruiter-hub/shortlists` / `PATCH /shortlists/:id`) atomically syncs `RecruiterMatch.status` (`shortlisted` or `rejected`) across both canonical `User._id` and legacy `Candidate._id` aliases, while `auditLogMiddleware` + explicit controller logs persist `AuditLog` events consumed by `RecruiterAnalyticsService` and `ActivityLogsComponent`.
