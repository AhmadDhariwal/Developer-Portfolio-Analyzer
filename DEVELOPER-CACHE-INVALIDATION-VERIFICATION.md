# Developer cache invalidation verification

| Source event                                    | Affected consumer                                                | Automatic reload                                                         | Automatic deterministic recalculation                            | Manual regeneration required                          | Verified                                                          |
| ----------------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------- | ----------------------------------------------------- | ----------------------------------------------------------------- |
| GitHub accepts changed evidence                 | GitHub Analyze; Skill Gap; Recommendations; Portfolio; Dashboard | GitHub reads latest accepted; Dashboard listens for scoped browser event | Skill Gap and Recommendations evaluate saved evidence on request | Optional paid enrichment remains explicit             | GitHub HTTP/MongoDB fixture; downstream browser chain outstanding |
| GitHub sync fails or loses lease                | Owned GitHub result, Repository                                  | Saved query returns previous accepted result                             | No                                                               | Retry Sync                                            | HTTP/MongoDB including takeover and 31-second hold                |
| Resume upload or active file changes            | Resume, Skill Gap, Recommendations, Portfolio, Dashboard         | Existing invalidation paths; obsolete prior resume view response ignored | Existing on-request policy                                       | Resume reanalysis explicit                            | Resume component test                                             |
| Profile career context changes                  | Dashboard and scoped analysis consumers                          | Dashboard coalesces profile and source events                            | Existing on-request policy                                       | Optional AI explicit                                  | Dashboard frontend suite; live browser outstanding                |
| Integration insights change                     | Portfolio, sprint context, Dashboard                             | Existing manual sync invalidations                                       | Portfolio score on request                                       | Provider sync remains explicit when initiated from UI | Existing suites; live provider chain outstanding                  |
| Course progress saved                           | Dashboard and report reads                                       | Scoped Dashboard event                                                   | No catalog recalculation scheduled by frontend                   | Report generation remains explicit or scheduled       | Frontend event unit tests; exact report latency outstanding       |
| Interview completed / Sprint changed            | Dashboard and report reads                                       | Prior invalidation paths                                                 | Progress calculated from stored records                          | Existing report/sprint generation policy              | Broad regression attempted                                        |
| Report generated                                | Dashboard and notifications                                      | Existing saved report reads and notification events                      | No                                                               | Existing user or scheduler workflow                   | Live browser chain outstanding                                    |
| News/jobs ingestion                             | Feed and Dashboard summaries                                     | Existing scheduled and saved reads                                       | No                                                               | Existing feed refresh controls                        | Full stack outstanding                                            |
| Dashboard-only mutation signal from another tab | Dashboard                                                        | Scoped read revalidation                                                 | No                                                               | No                                                    | Storage-event unit test verifies Recommendations cache retained   |

The GitHub lease uses the existing MongoDB lock collection and key github-save:<accountId>. It lasts 30 seconds, is renewed every 10 seconds, and is fenced in the acceptance transaction. Public preview caching stays separate from the owner-scoped cache read used by the three downstream consumers. The Redis GET/PTTL code from the committed baseline was preserved.

Historical reports, saved recommendations and saved scenario records are separate from current analysis results. The table does not claim all dependency permutations were exercised.
