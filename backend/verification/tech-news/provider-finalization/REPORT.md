## Confirmed defects and changes

1. **Kubernetes feed envelope and metadata parsing.** The official Hugo generator includes 50 entries with full escaped article content. A synthetic generator-shaped feed of **1,568,574 UTF-8 bytes** failed the staged baseline reader with `Invalid RSS`, before transport/parser compatibility was corrected. Kubernetes alone now permits an 8 MiB response and parser envelope; all other discovery adapters keep the 1 MiB limit and broad JSON keeps 2 MiB. Metadata remains capped at 40 entries with empty RSS descriptions. UTF-8 bytes, rather than JavaScript character count, enforce bounds. Whitespace around CDATA, numeric entities and metadata-field attributes are handled. DTD/entities remain prohibited; redirects and retries remain disabled. This proves a real compatibility defect, **not** the unobserved byte size/cause of today's live Kubernetes failure. A normal post-reset live check remains necessary.
2. **Admission denials looked like failed adapters.** Broad fetchers discarded reservation reason/deadline and the fixed-feed loop replaced denied outcomes with generic failures. They now retain sanitized `status`, `reason`, `nextEligibleAt`, `failureType` and HTTP status. A denied reservation causes zero transport calls and does not increase transport-failure counts. Actual failed HTTP attempts retain their failure classification without leaking upstream messages or URLs. The restarted runtime now records `quota_limited/interval` or `quota_limited/daily_budget` and “Provider waiting for admission.” instead of a fabricated generic transport fault.
3. **Malformed HTTP-200 broad payloads looked like successful empty feeds.** NewsAPI status/array, GNews articles/errors, HN hits, DEV list and Reddit children envelopes are validated within the governed request lifecycle. Invalid envelopes now produce `invalid_payload`, with ordinary failure/circuit accounting rather than an empty-success claim. Valid empty arrays remain successful.
4. **One malformed row discarded valid articles.** Several converters dereferenced null rows. They now reject malformed rows individually; valid neighbors survive. Removed/deleted Reddit content is excluded. HN falls back to a genuine original URL when no numeric story ID exists, rather than manufacturing an `id=undefined` discussion link. No full HN/Reddit bodies are stored.
5. **Incorrect upstream reset semantics.** The six-hour unknown-window fallback overrode explicit shorter reset windows; GitHub exhausted-primary-quota 403 could be mislabeled access-denied, and Reddit relative seconds were interpreted as epoch time. A regression reproduced the incorrect reason. Known GitHub epoch/Reddit relative reset and Retry-After windows are now honored, exhausted remaining counts are classified `upstream_rate_limit`, and unknown windows still fail closed for six hours. Existing longest-cooldown protection, sibling propagation, counters and per-adapter/family limits remain intact.

## Full pipeline and capabilities

Configuration validation and the platform news setting precede credentials/approval/budget checks. Every admitted HTTP attempt obtains its real source/family reservation first; denied or disabled sources do not contact upstreams. Normalized metadata then passes valid date, safe URL, attribution, source-approval and source-aware expiry checks. `NewsArticle` upserts use canonical URL identity and merge technology/search tags. Durable catalog versions invalidate query candidates across processes before public reads adopt new data. The compatibility pool is published only after persistence and under the token-owned ingestion lease.

The controlled scheduled test accepted nine sources in its first cycle because shared GitHub pacing correctly denied the second GitHub request. It simulated expiry of **fixture-owned interval keys only**, without resetting quota counters, then accepted the advisory in the next cycle. It persisted one record from all ten sources, inserted zero duplicates on replay, verified per-source publication-based expiry, attribution/tags/indexes, immediate cross-reader adoption and source revocation, and consumed zero discovery jobs.

HN/DEV keyword adapters support bounded public keyword discovery. GitHub releases require reviewed repository topics; advisories support bounded security-topic filtering. Kubernetes/Lobsters/Cloudflare supply fixed or taxonomy-selected feeds with local matching, not arbitrary upstream full-text search. NewsAPI/GNews upstreams support keyword search, but this application uses them for scheduled fixed broad queries only. Reddit is scheduled approved-subreddit rotation only. Enabling an env flag does not add these three restricted providers to Explore discovery.
