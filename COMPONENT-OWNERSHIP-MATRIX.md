# Component Ownership Matrix

## Architectural Boundary Rules
- **Single Cross-Role Exception Identified:** `frontend/src/app/features/recruiter/recruiter-hub-routing.module.ts` imports `NotificationsComponent` from `features/developer/pages/notifications/notifications.component`. All other cross-role imports and `shared/core -> features/` imports are `0`.
- **Single-Instance Reusable UI:** `<app-confirm-dialog>` (`shared/components/confirm-dialog/`), `<app-ui-empty-state>` (`shared/components/empty-state/`), `<app-ui-loader>` (`shared/components/loader/`), `<app-shared-message>` (`shared/components/message/`), and shared styles (`shared/styles/`).
